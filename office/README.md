# คู่มือเปิดและหยุด AI Agency Office

## เปิดตัวจำลองในแชท

กลับไปที่ข้อความ **AI Agency Office จำลอง** ในบทสนทนานี้ แล้วคลิกห้องหรือกด **เดินงานตัวอย่าง** ตัวจำลองใช้ภาพตัวละคร 3D และมีสถานะกับแชทตัวอย่าง เปิดได้จากข้อความเดิมโดยไม่ต้องรันคำสั่งหรือเปิด Local preview ปิดแชทหรือออกจากหน้านี้เพื่อหยุดดูตัวจำลอง

## เปิดออฟฟิศที่รันงานผ่าน Codex

ใช้เครื่องที่มีไฟล์โปรเจกต์ Python 3.11 ขึ้นไป และ Codex CLI ที่ล็อกอินและรันคำสั่งได้ เปิด Terminal ในโฟลเดอร์ `agency-team` แล้วรัน

```sh
python3 office/server.py
```

บน Windows ใช้ `py -3 office/server.py` ได้ถ้าติดตั้ง Python Launcher ไว้ เปิด [หน้าออฟฟิศในเครื่อง](http://127.0.0.1:8765) ในเบราว์เซอร์บนเครื่องเดียวกับที่รันคำสั่ง ฉาก 3D โหลด Three.js จาก CDN

## สั่งงานในแชททีมรวม

1. เปิด **ทีมรวม** แล้วส่งโจทย์ครั้งเดียว ระบบจะเลือกเฉพาะตำแหน่งที่เกี่ยวข้องและแสดงว่าใครรับงานอะไร
2. งานที่ต้องอาศัยผลจากตำแหน่งก่อนหน้าจะเริ่มเมื่อผลงานต้นทางเสร็จ ดูสถานะและคำตอบของทุกตำแหน่งได้ในแชทกลุ่ม
3. หากต้องการส่งงานให้คนเดียว ให้คลิกการ์ดตำแหน่งด้านล่าง หรือคลิกตัวละครในฉาก 3D

> ช่วยคิดโพสต์ Awareness วันลอยกระทง 3 ไอเดีย เลือก 1 แนว แล้วส่งต่อให้กราฟิกทำบรีฟภาพ และให้ทีมวิดีโอทำสตอรีบอร์ด Reels 15 วินาที

รุ่นนี้ให้ Codex ทำงานแยกตามบทบาทและส่งร่างกลับมาเป็นข้อความ เช่น แคปชัน บรีฟภาพ สตอรีบอร์ด ใบเสนอราคา หรือโค้ดตัวอย่าง ตัวรันเข้าถึงไฟล์แบบอ่านอย่างเดียว การสร้างไฟล์ภาพหรือคลิป แก้เว็บ และส่งงานถึงลูกค้าต้องใช้ขั้นตอนหรือเครื่องมือเพิ่มเติม หน้า GitHub Pages เป็นเดโมสาธารณะ สำหรับงานจริงให้ใช้ตัวรัน Codex ในเครื่องตามขั้นตอนด้านบน

## หยุดตัวรัน

รอให้งานที่ต้องการเสร็จและคัดลอกคำตอบที่ต้องการเก็บ จากนั้นกด **Ctrl+C** ใน Terminal ที่รัน `office/server.py` การปิดแท็บเบราว์เซอร์อย่างเดียวยังปล่อยให้เซิร์ฟเวอร์ทำงานอยู่

## ตำแหน่งไฟล์และผลลัพธ์

- `/workspace/agency-team/office/` เก็บคู่มือ หน้าจอ `index.html` และตัวรัน `server.py`
- `/workspace/agency-team/.codex/agents/` เก็บไฟล์ตั้งค่าผู้ช่วยทั้ง 6 ตำแหน่ง
- `/workspace/work/agency-office-styled-simulation.html` เก็บตัวจำลองพร้อมการ์ดตัวละคร 3D ที่แสดงในแชท
- `/workspace/generated_images/` เก็บภาพที่สร้างใน Cloud
- งานและข้อความจากตัวรันเก็บใน `office/data/jobs.json` หลังเปิดใหม่ งานที่ค้างจากการหยุดตัวรันจะแสดงว่าไม่สำเร็จ รุ่นนี้ส่งมอบคำตอบข้อความในแชท
