# เริ่มใช้ทีมใน Codex

เปิดโฟลเดอร์ `/workspace/agency-team` เป็นโปรเจกต์ Codex เพื่อให้โปรเจกต์อ่าน `AGENTS.md` และตำแหน่งจาก `.codex/agents/` หากทำต่อในแชทนี้ ให้ใช้คำสั่งด้านล่างได้เลยโดยระบุพาธโปรเจกต์

## ตำแหน่งทีมหลัก

1. Sales & Account Executive
2. Content Planner
3. Graphic Designer
4. Video Editor (แนวงานสไตล์ Gen Z)

## คำสั่งแรก

> ใช้ทีมใน /workspace/agency-team เรียกSales & Account Executive ช่วยหากลุ่มลูกค้าสำหรับบริการ [ใส่บริการ] และร่างข้อความทักให้ฉันตรวจ

## ทีมเบื้องหลัง

SEO Specialist และWeb Developerรับช่วงต่อเมื่องานของทีมหลักเกี่ยวกับคำค้น หน้าบริการ หรือการแก้เว็บ ผลงานส่งกลับมารวมในสรุปเดียวให้เจ้าของตรวจ

## คำสั่งตามงาน

- เรียกฝ่ายขาย ร่างใบเสนอราคาจากบรีฟนี้ [วางบรีฟ] ใช้ราคาที่ฉันให้และทำเครื่องหมายรายการที่ต้องยืนยัน
- เรียกทีมคอนเทนต์ส่งบรีฟให้ผู้ช่วยกราฟิกและนักตัดต่อ ทำโพสต์หนึ่งชิ้นกับคลิปก่อน–หลังแนวตั้งจากไฟล์ที่แนบ ส่งให้ฉันตรวจ
- เรียก SEO และWeb Developer ใช้รายงาน Search Console ที่แนบ ตรวจหน้าบริการและเสนอรายการแก้ตามลำดับ

เมื่อต้องการตรวจเว็บ ให้เริ่มจาก URL สาธารณะ เมื่อต้องแก้เว็บจึงเชื่อม repo หรือใช้ CMS ตามระบบเว็บ เมื่อต้องวัดคำค้นจริงจึงใช้ Search Console หรือไฟล์ส่งออก เมื่อต้องผลิตคลิปให้ส่งไฟล์ภาพหรือวิดีโอต้นฉบับ
